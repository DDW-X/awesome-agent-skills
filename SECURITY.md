# Security Policy

## 1. Supported Versions

We actively maintain and provide security updates for the current major release of the `<DDW-X>` Agentic Knowledge Base:

| Version | Supported |
|:-------:|:---------:|
| `v2026.x` | :white_check_mark: |
| `< v2026.0` | :x: |

---

## 2. Reporting a Vulnerability

The `<DDW-X>` team takes the security and integrity of our Agent Skills and FastMCP bridges seriously. If you discover a security vulnerability, unintended bypass, or potential supply chain risk in this repository:

1. **DO NOT file a public issue.** Publicly disclosing vulnerabilities exposes the community to unnecessary risk.
2. Submit a private report via **GitHub Security Advisories** or email our security desk directly:
   - **Email**: [`DDW.X.OFFICIAL@gmail.com`](mailto:DDW.X.OFFICIAL@gmail.com)
   - **Subject**: `[SECURITY VULNERABILITY REPORT] <Component Name>`
3. Include the following details in your advisory:
   - Specific skill file or script affected (e.g., `Skills-CS/Advanced Reverse Engineering & Ghidra MCP.md`).
   - Detailed step-by-step reproduction instructions.
   - Proof of Concept (PoC) or affected AST pattern if applicable.
   - Potential impact and recommended remediation.

---

## 3. Vulnerability Response Timeline

- **Initial Acknowledgment**: Within 24-48 hours.
- **Triage & Impact Assessment**: Within 5 business days.
- **Patch Release & Public Advisory**: Coordinated release following remediation deployment.

Thank you for helping keep the open-source agentic community secure and resilient!
